Bongo Cat AutoClicker
Fonctionnalités;

Mode Souris: simule des clics de souris.
ode Clavier : simule des frappes au clavier.
Mode Combiné : utilise la souris et le clavier simultanément.

raccourcis clavier :
  - `F6` : démarrer / mettre en pause.
  - `F7` : arrêter l'AutoClicker.
  - `F10` : quitter le programme.
- 📊 **Compteurs** : affiche le nombre d'événements envoyés.

## 🛠️ Technologies utilisées

- Python
- Tkinter
- PyAutoGUI
- PyDirectInput
- Keyboard

## 🚀 Installation

1. Installer Python.
2. Installer les bibliothèques nécessaires :

```bash
pip install pyautogui pydirectinput keyboard
```

3. Télécharger ou cloner le projet.
4. Lancer le programme :

```bash
python main.py
```
